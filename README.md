# Driftwood Isle

משחק הישרדות נעים על אי בודד, בתצוגה מלמעלה, שרץ כולו בדפדפן.
נסחפים לחוף, אוספים חומרים, בונים כלים, שומרים על מדורה בוערת בלילה ובונים רפסודה כדי להפליג הביתה.

## הרצה

אין צורך בהתקנה או בבנייה. פותחים את `index.html` בדפדפן.
כדי לפרסם ברשת: ב-GitHub נכנסים ל-Settings → Pages ובוחרים את הענף `main` ואת התיקייה הראשית (root).

## שליטה

| מקש | פעולה |
| --- | --- |
| WASD או החיצים | הליכה |
| E או רווח | שימוש / איסוף |
| C | חלון יצירה (Crafting) |
| F | אכילת המזון הטוב ביותר |
| H | עזרה |
| M | השתקת קול |
| Esc | ביטול הצבת מבנה |

בטלפון מופיעים ג'ויסטיק וכפתורי Use / Eat / Craft.
המקשים נקראים לפי מיקומם הפיזי (`e.code`), כך שהם עובדים בכל פריסת מקלדת, גם בעברית.

## מבנה הקוד

בלי ספריות ובלי שלב בנייה (build): HTML, ‏CSS ו-JavaScript רגילים, ורק הגופנים מגיעים מ-Google Fonts.
הקבצים נטענים כ-`<script>` רגילים לפי הסדר שב-`index.html`, ולכן המשחק נפתח גם בלחיצה כפולה על הקובץ, בלי שרת.

```
index.html        המבנה: מסך פתיחה, HUD, חלונות, ורשימת הסקריפטים
css/style.css     כל העיצוב
js/
  util.js         כלי עזר: מתמטיקה, רעש (noise), מספרים אקראיים, localStorage, הגדרות DEBUG
  world.js        מפת הגובה של האי, הבריכה, ההר, ציור השטח וקו החוף
  objects.js      יצירת עצים, סלעים, שיחים, ארגזים ועוד; חיפוש מהיר לפי מיקום (nearby)
  items.js        פריטים, מזון, מתכוני יצירה ואייקונים
  audio.js        צלילים ב-WebAudio
  state.js        מצב המשחק S, שמירה וטעינה
  canvas.js       הקנבס, גודל המסך והזום
  input.js        מקלדת
  actions.js      אינטראקציה עם העולם, יצירה והצבת מבנים
  quests.js       רשימת המשימות
  ui.js           HUD, מלאי, שעון, מפה קטנה
  update.js       הלולאה: תנועה, צרכים, מזג אוויר, סרטנים, חלקיקים, הפלגה
  render.js       ציור העולם, תאורה, גשם, ופונקציות הציור DRAW
  controls.js     שליטה במגע, כפתורים, התחלת משחק
  debug.js        מצב debug (פעיל רק עם ?debug)
  main.js         אתחול ולולאת הפריימים
```

**חשוב:** כל הקבצים חולקים משתנים גלובליים, ולכן הסדר ב-`index.html` משנה. קוד שרץ מיד בטעינה יכול להשתמש רק במה שהוגדר בקבצים שלפניו. קוד בתוך פונקציות יכול להשתמש בכל דבר.

## מצב debug

מוסיפים `?debug` לכתובת, למשל `index.html?debug` או `https://sdhdavid.github.io/island-survival-game/?debug`.
מופיע פאנל בצד שמאל (המקש <kbd>`</kbd> מסתיר ומציג אותו) עם:

- **פריטים:** חומרים, כל הכלים, מזון, ערכת רפסודה, ריקון התיק
- **זמן ומזג אוויר:** האצה ×5 / ×20 / ×60, קפיצה לבוקר / צהריים / ערב / לילה / יום הבא, גשם
- **שחקן:** God mode (הצרכים לא יורדים), מילוי או ריקון צרכים, הצגת hitboxes
- **שיגור:** לחוף, לבריכה, להר ולכל אחד מהארגזים
- **משימות:** דילוג למשימה הבאה, התחלה מחדש
- **מידע:** FPS, מיקום, גובה השטח, שעה, גשם, מספר אובייקטים

משחק במצב debug נשמר בנפרד, כך שהוא לא נוגע במשחק האמיתי שלך.
