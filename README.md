# Driftwood Isle

משחק הישרדות נעים על אי בודד, בתצוגה מלמעלה, שרץ כולו בדפדפן.
נסחפים לחוף, אוספים חומרים, בונים כלים, שומרים על מדורה בוערת בלילה ובונים רפסודה כדי להפליג הביתה.

## הרצה

אין צורך בהתקנה או בבנייה. פותחים את `index.html` בדפדפן.
כדי לפרסם ברשת: ב-GitHub נכנסים ל-Settings → Pages ובוחרים את הענף `main` ואת התיקייה הראשית (root).

## שליטה

| מקש | פעולה |
| --- | --- |
| WASD או החיצים | הליכה |
| E או רווח | שימוש / איסוף |
| C | חלון יצירה (Crafting) |
| F | אכילת המזון הטוב ביותר |
| H | עזרה |
| M | השתקת קול |
| Esc | ביטול הצבת מבנה |

בטלפון מופיעים ג'ויסטיק וכפתורי Use / Eat / Craft.
המקשים נקראים לפי מיקומם הפיזי (`e.code`), כך שהם עובדים בכל פריסת מקלדת, גם בעברית.

## מבנה הקוד

הכול נמצא בקובץ אחד, `index.html`: HTML, ‏CSS ו-JavaScript בלי ספריות חיצוניות (רק גופנים מ-Google Fonts).
הסקריפט מחולק לאזורים לפי כותרות `// ===== ... =====`:

- **World constants / Terrain generation**: מפת גובה פרוצדורלית עם seed קבוע (`rawH`), הבריכה, ההר, ציור תמונת השטח ונקודות קו החוף לקצף הגלים.
- **Objects**: יצירת עצים, דקלים, סלעים, שיחים, עשב, מקלות, אבנים, צדפים וארגזים. הם מאוחסנים ברשת דליים (`nearby`) לחיפוש מהיר.
- **Items & recipes**: הגדרות הפריטים (`ITEMS`), המזון ומתכוני היצירה (`RECIPES`).
- **Icons**: אייקוני הפריטים מצוירים על canvas.
- **Audio**: צלילים שנוצרים ב-WebAudio: גלים, גשם, ציפורים, צרצרים ואפקטים.
- **State / save**: מצב המשחק `S`, שמירה ב-`localStorage` (`serialize` / `loadInto`).
- **Interaction**: `findTarget` → `actionFor` → `doAct`.
- **Quests**: רשימת המשימות `QUESTS` לפי הסדר.
- **Update / Rendering**: הלולאה הראשית, מחזור יום-לילה, מזג אוויר, תאורה, חלקיקים ופונקציות הציור `DRAW`.
